def apply_twice(func, value):
    """Apply a function twice to a value."""
    return func(func(value))

result = apply_twice(lambda x: x + 3, 7)

💡 Why DBSCAN?

Unlike K-Means which enforces spherical boundaries, DBSCAN groups points that are tightly packed together, discovering clusters of arbitrary non-convex shapes while cleanly filtering noise without bias.
